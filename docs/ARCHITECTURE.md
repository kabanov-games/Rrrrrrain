# Архитектура «Хххххх Ххххххх»

Источник правил — `CONCEPT.md`. Этот файл описывает, как текущий код это реализует, и куда класть новые системы.

## Слои

```
клиент (Three.js, Colyseus.js)
        │  input / cast / pickup / phase
        ▼
сервер  Colyseus ArenaRoom          — комната, тик 20 Hz, сообщения
        server/src/systems/*        — правила боя, лута, забега, AI
        shared/index.js             — каталоги и формулы (клиент + сервер)
        server/src/schema.js        — синхронизируемое состояние
```

Сервер авторитативен: HP, золото, XP, предметы, враги, портал и фазы живут в `GameState`. Клиент шлёт ввод и рисует снапшот плюс FX.

Стек сейчас Node + Colyseus, не Java из §7 CONCEPT.md. Менять рантайм не требуется, пока не будет отдельного решения по деплою.

## Фазы забега (`state.phase`)

| Фаза | Что происходит |
|---|---|
| `hub` | лобби, хранилище, портал на арену |
| `arena` | этап круга, таймер сложности, поиск телепорта |
| `portal_ready` | оборона 90 с завершена, можно next_stage / loop / босс |
| `bazaar` | Базар Ньюта через синий портал |

Переходы: `server/src/systems/runFlow.js`.

## Серверные системы

| Модуль | Ответственность |
|---|---|
| `systems/stats.js` | max HP и множитель урона от уровня + стаков |
| `systems/combat.js` | касты, хитскан, снаряды, урон, дроны, реген |
| `systems/loot.js` | сундуки, алтари, принтер, утильщик, дроны, снаряжение |
| `systems/runFlow.js` | хаб ↔ арена ↔ базар, Loop, wipe, XP/золото |
| `systems/director.js` | спавн, элиты, патруль/агро, AI Director |
| `systems/messages.js` | регистрация Colyseus-сообщений |
| `ArenaRoom.js` | фасад комнаты: join/leave, тик, делегирование |

Новую механику класть в систему по таблице, не раздувать `onCreate`.

## Клиент

`client/src/main.js` — цикл кадра, сеть, HUD. Остальное:

- `world.js` / `worldV3.js` — хаб и арена
- `controller.js` — третье лицо
- `enemies3d.js` / `enemyV3.js` — визуал мобов
- `netherPortal.js` — портал
- `weaponHud.js` — иконки способностей

Клиент не считает лут и HP: только предикт движения и эффекты.

## Сообщения (контракт)

Основные: `input`, `cast`, `pickup`, `activate_portal`, `equipment`, `ping`, `hub_*`, `enter_arena` / `next_stage` / `loop_run`, `debug`.

Обратная связь: патч `GameState` + `fx` + `chat`.

## Соответствие CONCEPT.md (сейчас)

Есть: core loop (высадка → лут → оборона телепорта → этап/Loop/Mithrix), XP, золото, лунные монеты, стакающиеся пассивки, алтари, принтер/утильщик, базар, Q-снаряжение, пинг, кооп до 4, таймер сложности.

Нет / заглушки: loadout 4 способностей, артефакты, eclipse, logbook, Java-сервер, пиксельный рендер вместо Three.js, полноценный HUD по макету GDD.

## Правило для агентов

1. Числа и каталоги — только `shared/index.js`.
2. Мутации стейта — только серверные системы.
3. Не дублировать формулы на клиенте, кроме отображения (HUD читает state).
