# Репозиторий и релизы

## Коммиты

Каждый законченный шаг (фича, фикс, документация) коммитится и пушится в рабочую ветку. Не копим пачку несвязанных правок в одном коммите.

## Релизы

GitHub Release и git-тег `vX.Y.Z` — только для **стабильных** сборок на `main`:

- забег проходит (лобби → арена → телепорт → этап/Loop/хаб);
- нет известных блокирующих крашей сервера;
- номер версии в `GAME.version` совпадает с тегом.

Нестабильное (рефактор, WiP, переименование без геймплея) в релиз не идёт.

Текущая стабильная линия: **v0.0.9.1** (цикл concept2 на `main`). Следующий релиз — по указанию или когда на `main` снова будет играбельный согласованный срез.
